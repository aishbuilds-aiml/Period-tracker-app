

# 🌸 Menstrual Health Awareness Website Plan

## Overview
A comprehensive, culturally-appropriate menstrual health awareness website designed for Indian teenage girls, college students, and young women. The website will feature a soft, calming design with educational content presented in a respectful and easy-to-understand manner.

---

## 🎨 Design Theme
- **Color Palette**: Soft pink (#FFE4E6), lavender (#E9D5FF), beige (#FEF3E2), white backgrounds
- **Typography**: Friendly, readable fonts (Inter for body, rounded headings)
- **Visual Style**: Soft gradients, rounded corners, calming illustrations, icons from Lucide
- **Layout**: Clean cards, spacious sections, mobile-first responsive design

---

## 📄 Pages & Features

### 1. **Home Page**
- Welcoming hero section with supportive messaging
- Website purpose statement
- Quick navigation cards to main sections
- Call-to-action buttons: "Learn More", "Myths vs Facts", "Track Your Cycle"
- Testimonials or encouraging quotes

### 2. **About Menstruation**
- What is menstruation (simple explanation)
- Step-by-step menstrual cycle breakdown with visual timeline
- Normal period duration and common symptoms
- Interactive cycle phase cards

### 3. **Menstrual Hygiene**
- Hygiene practices during periods
- How to use and properly dispose of sanitary products
- Tips for cleanliness and health
- Do's and Don'ts checklist

### 4. **Myths vs Facts**
- Common myths in Indian society (formatted as cards)
- Scientific facts debunking each myth
- Interactive reveal format (click to see the truth)
- "Share this fact" feature for awareness

### 5. **Menstrual Products**
- Sanitary pads, tampons, and menstrual cups explained
- Pros and cons comparison table
- How to choose the right product
- Environmental considerations

### 6. **Health & Safety**
- Warning signs and when to see a doctor
- Signs of infection
- PMS and cramps management tips
- Self-care recommendations

### 7. **FAQ Section**
- Searchable frequently asked questions
- Accordion-style expandable answers
- Categories for easy navigation
- Common concerns addressed sensitively

### 8. **Contact / Help**
- Working contact form (with backend)
- Helpline information (Indian health helplines)
- Emergency guidance note
- Privacy assurance message

---

## 🛠 Special Features

### Period Tracker Calculator
- Input last period start date
- Select average cycle length
- Calculate and display next expected period
- Show fertile window (optional)
- Visual calendar indication

### Search Functionality
- Global search bar in navigation
- Search across all content
- Instant results with page navigation

### Accessibility Features
- High contrast text
- Readable font sizes
- Keyboard navigation support
- Alt text for all images/icons

---

## 🔧 Technical Implementation

### Frontend Structure
- React with React Router for navigation
- Responsive design using Tailwind CSS
- Reusable components (cards, sections, navigation)
- Lucide icons for visual elements

### Backend (Lovable Cloud)
- Edge function for contact form submission
- Email notifications for form responses
- Secure data handling

---

## 📱 Responsive Design
- Mobile-first approach
- Hamburger menu for mobile navigation
- Touch-friendly buttons and interactions
- Optimized images and layouts for all screen sizes
